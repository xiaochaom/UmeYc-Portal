## 本版更新

- 「本地文件」和「网页」（地址输入与最近浏览）改为 Steam / Decky 原生弹窗，支持方向键或左摇杆移动焦点、A 确认、B 返回。
- 本地文件中的文件夹选择、删除确认也使用原生弹窗；B 返回上一层，打开失败时保留弹窗并显示原因。
- 弹窗打开期间隐藏攻略并暂停阅读快捷键，关闭后恢复原来的阅读器开关状态。扫码传送继续保持左侧面板布局。
- 按新需求调整启动行为：重启系统或重载插件后，阅读器默认关闭，保留当前地址、历史和其他设置；不再恢复上一版记住的开启状态。
