# v1.0.0-zh-cn.28

- 阅读器显示时按 R2 切换最大窗口与侧栏。最大窗口覆盖整个 Deck 屏幕，网页标题栏与快捷栏面板隐藏；只控制窗口大小，保留视频播放器自身的全屏状态和快捷栏的开关状态。
- 网页显示时按 L2 发送一次空格，切换视频播放／暂停；长按不重复，本地攻略和弹窗中不发送。
- 「扫码传送」下方新增「使用说明」，通过原生弹窗说明各个键位，方向键上下浏览，确认或返回关闭。
- 「打开／关闭」按钮移至插件页面顶部，进入页面即可操作。
- 两种模式都随「…」同开同关。最大窗口时收起快捷栏前暂停视频，再展开后恢复窗口和播放进度；手动暂停的视频保持暂停。
- 最大窗口支持网页和本地攻略，不需要启用 R3。保留原有可选的 R3/F 网站快捷键，以及 L1/R1/L3 缩放和右摇杆控制。
- 关闭阅读器后重开默认返回侧栏，插件重载后仍默认关闭；地址与历史保留。
- 验证：157 项前端测试、55 项 Python 测试通过；Deck 程序注入验证 R2 保留播放器全屏状态、L2 单次空格与暂停恢复、「…」同步显隐及说明弹窗。截图确认最大窗口无遮挡，实机确认打开／关闭按钮位于顶部。尚未由用户实体按键确认。
